# 時間帳本 Time Ledger

一個記錄「時間實際花在哪裡」的小工具。目標不是排出完美的計畫，而是讓自己看清楚每天、每週的真實分配，減少迷茫感。

## 現在能做什麼

- **一鍵計時**：點類別開始計時，換事情時點下一個類別，上一段自動結算
- **補記**：忘了計時可以事後補一筆
- **今天最重要的一件事**：每天寫一件，完成就打勾
- **當日分配**：24 小時色帶 + 各類別時數
- **週報**：最近 7 天的堆疊長條圖，以及自動產生的觀察（碩論時數對比上週、主線／逃避佔比、最常開始做碩論的時段等）

類別分成四組：

| 組別 | 類別 |
| --- | --- |
| 主線 | 碩論、求職 |
| 長期投資 | 托福單字、法文、課外書 |
| 生活 | 生活雜事、休息娛樂 |
| 逃避 | 滑手機／拖延 |

## 使用方式

純 HTML + JavaScript，不需要安裝或建置。直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages：

1. Repo → Settings → Pages
2. Source 選 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`
3. 幾分鐘後就能從 `https://<你的帳號>.github.io/time-ledger/` 打開

## 資料存在哪

在一般瀏覽器裡，資料存在該瀏覽器的 `localStorage`，**只在那台裝置、那個瀏覽器看得到**，清除網站資料就會消失。

（這份程式最初是 Claude 上的 Artifact，在那裡會改用帳號同步儲存；`connect()` 這段在一般瀏覽器中不會作用，可以保留也可以刪掉。）
